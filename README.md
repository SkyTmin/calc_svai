# Свая — калькулятор наклона

Мобильный калькулятор вертикальной проекции наклонной сваи. Чистые HTML, CSS и JavaScript, без зависимостей и сервера.

## Возможности

- Фактическая длина вдоль сваи → длина по вертикали.
- Обратный расчёт: длина по вертикали → длина вдоль сваи.
- Угол от вертикали в градусах, минутах и секундах, либо смещение в мм на метр.
- Для мм/м явно выбирается основание: метр по вертикали или вдоль сваи.
- Схема с длинами, горизонтальным смещением и углом. Угол на схеме может быть увеличен для читаемости; схема без масштаба.
- Копирование расчёта, поддержка запятой и точки, сохранение последних полей только в браузере (`localStorage`).
- Адаптивная разметка, системные шрифты, без сторонней аналитики и внешних библиотек.

## Формулы

`L` — длина вдоль сваи, `H` — вертикальная проекция, `X` — горизонтальное смещение, `α` — угол от вертикали.

```text
α = градусы + минуты / 60 + секунды / 3600
H = L × cos(α)
X = L × sin(α)
L = H / cos(α)  — обратный расчёт
```

Для `q` мм смещения на метр **по вертикали**: `α = atan(q / 1000)`.
Для `q` мм смещения на метр **вдоль сваи**: `α = asin(q / 1000)`.

Примеры:

| Длина вдоль сваи | Наклон | По вертикали |
| --- | --- | --- |
| 10,000 м | 12° 00′ 00″ | 9,781 м |
| 50,560 м | 12° 00′ 06″ | 49,455 м |
| 50,560 м | 12° 06′ 00″ | 49,437 м |
| 50,560 м | 140 мм на метр по вертикали | 50,072 м |
| 50,560 м | 140 мм на метр вдоль сваи | 50,062 м |

Вычисления выполняются без промежуточного округления. Результаты выводятся до 0,001 м; это округление, а не оценка точности исходных измерений. Вертикальная проекция равна глубине только для участка от соответствующего уровня отсчёта до нижнего конца. Калькулятор не оценивает допустимость наклона.

## Разработка

Исходники сайта находятся в `dist/`; это готовая папка для статического хостинга. Откройте её любым локальным HTTP-сервером, например:

```sh
python3 -m http.server 3000 --directory dist
```

Прямое открытие через `file://` не поддерживается, поскольку используются модули JavaScript.

Тесты, Node.js 20+:

```sh
npm test
```

## GitHub Pages

Ветка `main` содержит проект, ветка `gh-pages` — содержимое `dist/` для публикации. Настройка Pages: **Deploy from a branch → gh-pages → / (root)**.

После изменения файлов:

```sh
npm test
git add dist tests README.md package.json
git commit -m "Update calculator"
git push origin main
npm run deploy
```

Для публикации не нужны ключи в коде. Репозиторий: https://github.com/SkyTmin/calc_svai
